## 一、简历正文版（直接复制到简历「项目经历」栏）

**黑马程序员苍穹外卖** | 后端开发（独立开发） | 2026.09 - 2026.10

技术栈：Spring Boot 3.2.5、MyBatis-Plus 3.5.5、MySQL 8、JDK 17、WebSocket、Apache POI、Maven 多模块

- 独立从零搭建外卖点餐系统后端，采用 Maven 三模块架构（common / pojo / server），覆盖管理端与用户端共 40+ 接口。
- 手写 JWT（HS256）实现双端鉴权隔离：管理端/用户端两套密钥、请求头、载荷完全独立，并用常量时间比较防时序攻击。
- 基于 ThreadLocal 传递登录上下文，结合 MyBatis-Plus MetaObjectHandler 实现公共字段自动填充，替代 AOP 方案（零反射、零额外依赖）。
- 支付模块用「订单状态机 + 唯一索引」实现幂等，避免重复支付；WebSocket 实现来单/催单实时推送，商家端秒级响应。
- 用 Apache POI 实现营业额/用户/订单/销量 Top10 统计报表与 Excel 导出，并配套纯静态管理端 SPA 演示前端。

## 二、面试口述版（STAR 法则，面试官问"讲一下这个项目"时用）

### S — 背景（Situation）

求职目标 Java 后端，需要一个能体现工程能力、又贴近真实业务的完整项目。因此从零搭建了一个外卖点餐系统，覆盖「商家管理菜品/套餐 → 用户下单 → 支付 → 商家接单配送」完整闭环。

### T — 任务（Task）

独立完成架构设计、数据库建模、代码实现、联调测试。不做"套模板"的 demo，重点把鉴权、事务、幂等、实时推送、统计这几个后端高频考点落地成真实代码。

### A — 行动（Action）

**1. 架构与分层**
- Maven 三模块拆解：`sky-common`（公共工具/常量/异常）、`sky-pojo`（实体/入参/出参）、`sky-server`（业务），实现复用与解耦。
- 分层遵循 Controller → Service → Mapper，复杂 SQL 走 XML（join 分类名、聚合统计），单表走 BaseMapper。

**2. 双端鉴权（核心亮点）**
- 不引第三方 JWT 库，手写 HS256 实现签名/验签。
- 管理端、用户端两套独立密钥 + 独立请求头（`token` vs `authentication`）+ 独立载荷（`empId` vs `userId`），天然隔离，互不越权。
- 签名比较用 `MessageDigest.isEqual` 常量时间比较，防时序攻击。

**3. 登录上下文与公共字段填充**
- 拦截器验签后把 `empId` 存入 ThreadLocal（`BaseContext`），请求内任意层可读，免逐层传参；`afterCompletion` 里 `remove` 防线程池复用串号 + 内存泄漏。
- 公共字段（createTime/updateTime/createUser/updateUser）用 MyBatis-Plus `MetaObjectHandler` 自动填充，`strictInsertFill` 按实体注解精确填充，替代课程原版的 AOP + 反射遍历方案（零侵入、无额外依赖）。

**4. 关联表与事务**
- 菜品-口味（一对多）、套餐-菜品（多对多中间表）增删改全部 `@Transactional`，失败整体回滚。
- 更新用「先删后插」全量替换，并做起售/被引用等业务约束校验。

**5. 价格快照（防篡改 + 历史可追溯）**
- 下单时后端重新查 dish 表补 `name`/`price`，不信任前端传价，防止篡改。
- 订单存价格快照，后续改菜品价不影响历史订单。

**6. 支付幂等（核心亮点）**
- 用「订单状态机 + 订单号唯一索引」实现幂等：重复支付回调直接返回 duplicate，不重复入账。
- 本机无 Redis，用数据库方案替代，反而更硬核（面试可主动提：若生产环境高并发，会加 Redis 缓存 + 分布式锁）。

**7. WebSocket 实时推送**
- `@ServerEndpoint` 实现来单/催单推送，按 type 分组的并发会话池 `ConcurrentHashMap` 管理连接。

**8. 统计报表与 Excel**
- 聚合 SQL 走 XML，实现营业额/用户/订单/销量 Top10 统计；POI 生成 xlsx 导出（中文文件名 UTF-8 编码）。

### R — 结果（Result）

- 交付 40+ 接口，全链路 curl 实测通过，统计结果与数据库交叉核对吻合。
- 配套纯静态管理端 SPA（零 CDN）演示，形成"后端 + 演示前端"完整闭环。
- 沉淀了 JWT 手写实现、幂等方案、状态机设计等可复用工程能力。

## 三、三个「主动引导面试官」的话术

1. 提到 JWT 时主动补一句："签名比较我特意用了常量时间比较，防时序攻击。"—— 这是多数候选人不知道的加分点。
2. 提到支付时主动说："本机没装 Redis，我用状态机 + 唯一索引做了幂等；如果上生产我会加 Redis 缓存热菜和店铺状态。"—— 顺势引出 Redis 储备。
3. 提到自动填充时主动说："课程原版用 AOP + 反射，我改成 MyBatis-Plus 原生回调，零侵入、无反射开销。"—— 体现你懂为什么。
