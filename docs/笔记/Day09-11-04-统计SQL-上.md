## 核心讲解

### 为什么走 XML
- `date_format(order_time, '%Y-%m-%d')` 按天分组——条件构造器写不了
- 聚合函数 + group by 属于复杂 SQL，项目约定「复杂走 XML、单表走 BaseMapper」

### 营业额口径（必背）
```sql
where status = 5           -- 只算「已完成」，待付款/取消不算营业额
group by date(order_time)  -- 按「下单日」分组
```

**为什么用 order_time 不用 checkout_time**：所有报表共用同一条时间轴（下单日），对账口径一致。

### 为什么 amount 可以直接 SUM
amount 是支付成功时才写入的实收金额，status=5 的订单 amount 必然有效，直接求和即可。
