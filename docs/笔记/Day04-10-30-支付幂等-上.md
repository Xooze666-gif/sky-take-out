## 核心讲解

### 幂等的定义
**同一个请求重复发 N 次，效果和发 1 次完全一样。**

### 为什么支付必须幂等
支付回调可能重复到达：用户网络抖动重试、微信服务端重推、用户连点两次。不幂等 = 同一笔订单入账两次。

### 第一重保险：状态机判断
```java
Orders order = orderMapper.selectOne(...订单号...);
if (order == null) throw ...;
if (order.getPayStatus() == PAID) {
    return "duplicate";   // 已支付过，秒回，不做任何操作
}
// 只有第一次执行到这里
order.setPayStatus(PAID);
order.setStatus(TO_BE_CONFIRMED);
orderMapper.updateById(order);
```
一句话：**先查状态，已处理过就秒回，没处理过才执行。**

### 为什么这能防住重复
第二次回调进来时，订单的 payStatus 已经是 PAID，第一行判断直接 return，后面的改状态、推 WebSocket 全都不执行。
