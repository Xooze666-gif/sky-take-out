## 核心讲解

### 条件聚合（orderStatistics）
```sql
sum(case when status = 5 then 1 else 0 end) as validOrderCount
```
一条 SQL 同时查出「总单数」和「有效单数」，不用查两遍。

### 销量 Top10 为什么 join
```sql
from order_detail od join orders o on od.order_id = o.id
where o.status = 5
```
先按订单状态过滤（只算已完成），再汇总明细。**过滤条件在 orders 表，数据在 order_detail 表，必须 join。**

### 区间查询的「+1 天」陷阱
```sql
order_time < date_add(#{end}, interval 1 day)
```
`<= end` 会漏掉 end 当天（end 是 00:00:00 的日期）。+1 天再 <，把 end 整天包进来。

### SQL 与 service 的分工
- SQL 查原料：按天的营业额/单数、按天新增用户
- service 算衍生指标：完成率 = 有效单/总单；客单价 = 营业额/有效单；totalUserCount = 按天累加
- 被问"为什么不用窗口函数在 SQL 里算累计"：可读性优先，数据量这个级别没差别，量大可上窗口函数
