## 官方苍穹外卖用 Redis 做什么（对照清单）
- 缓存店铺营业状态（user 端每次进首页都查，读多写少 → 最适合缓存）
- 缓存热门菜品（用户端浏览菜品，频率高）
- 购物车（官方用 Redis hash 存，你用 MySQL）
- 支付幂等标记（你用状态机 + 唯一索引）

## 三个必背概念
1. **穿透**：查一个数据库里不存在的数据，缓存永远不命中 → 布隆过滤器 / 缓存空值
2. **击穿**：热点 key 过期瞬间，大量并发打到数据库 → 互斥锁 / 逻辑过期
3. **雪崩**：大量 key 同时过期 → 过期时间加随机偏移

## 思考（为明天铺垫）
如果要缓存「店铺状态」，数据放 Redis 后，管理员改状态时除了改 MySQL 还要做什么？（答：删缓存或改缓存，保证一致性）
