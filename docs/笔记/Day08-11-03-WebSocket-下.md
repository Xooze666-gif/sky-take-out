## 核心讲解

### 推送的两个消费点（串联考点⑥）
1. `OrderServiceImpl.payment` 支付成功 → `sendToType("1", ...)` 推来单提醒
2. `OrderServiceImpl.reminder` 用户催单 → `sendToType("2", ...)` 推催单

### 消息格式
```json
{"type":1,"orderId":3,"content":"订单号 20261018134814145623"}
```
前端收到后按 type 区分弹窗样式。

### 无连接时的行为
`sendToType` 里先判空：没有 type 对应的在线连接就记日志跳过，**不报错**。这是健壮性设计——不能因为商家没开页面就让支付流程失败。
